# 06 磁盘规格与 200G

[← 目录](README.md)

口径：VPC 网络，**16 核 32G**，50 台设备的工厂，先不分库、不分文件机。

对 50 台设备：核数和内存够用；以后更可能缺的是内存和盘，不是核数。  
带宽约 25M 对 50 台设备够用。

---

## 盘怎么买

| 盘 | 建议 | 用途 |
|---|---|---|
| 系统盘 | **80～100G SSD** | 系统、程序。40G 太小 |
| 数据盘 | **200G 可以先买**（单独挂一块） | 数据库、设备历史、热附件 |

系统盘只放系统和程序；数据盘放库和日志；图纸/录像不要堆这两块，走对象存储。

200G 成立的前提：

- 图纸不大堆在数据盘
- 没有摄像头录像
- 采集不要长期存每秒原始波形

用到约七成（约 140G）再扩或加挂。

## 200G 等于多少数据

真正能用的按约 **140G** 算（盘不能 100% 堆满）。

| 存什么 | 大概多少能占满 200G |
|---|---|
| 工单、库存、用户表 | 几百万到上千万条也常常不到几十 G，单靠业务表很难吃满 |
| 50 台设备，每分钟一笔状态 | 大约 5～8 年 |
| 50 台设备，每 10 秒一笔 | 大约 1～1.5 年 |
| 50 台设备，每 1 秒原始点 | 大约 1～2 个月 |
| 照片（约 2M/张） | 约 10 万张 |
| 图纸 PDF（约 10M/份） | 约 2 万份 |
| 1 路摄像头录像 | 大约 7～10 天 |

50 台设备常见用法（几秒到几十秒一个点、热数据留 1 年、图纸不多、无录像），一年大约 50～120G。  
**200G ≈ 一年的 50 台设备常规监控 + 业务库。**

## 数据盘不能扩容怎么办

不等于整机报废。顺序：

1. **再挂一块新盘**（很多机型不能改大原盘，但允许加挂）
2. 图纸/备份改放到对象存储，原盘立刻变瘦
3. 新买更大一块盘，把数据拷过去，改挂载点，旧盘先留几天再卸
4. 再不行就拆：程序仍在原机，数据库改云数据库/另一台，文件改对象存储；域名仍指门口

同时省着花：日志 15～30 天、原始点位只留短周期、备份不堆同一块数据盘。

拷库换盘时最好有短窗口，避免写到一半。
