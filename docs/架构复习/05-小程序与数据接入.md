## 小程序怎么分用户

小程序也是全中国 **共用一个**，不要给每家工厂各申请一个。

```text
网站：同一个 www.goci.com
小程序：微信里同一个「你们的工业助手」
```

打开之后：

```text
微信给出 openid（哪个微信号）
  → 你们系统绑定：哪个员工、哪家工厂
  → 之后请求都带这个身份
  → 只返回这家数据
```

```text
微信号 openid  →  员工账号  →  工厂客户ID
```

没绑定过：先登录你们发的账号（或管理员邀请），绑一次。  
一个人管两家厂：登录后选进哪家。

小程序没有自己的云服务器、不用单独备案；只是手机壳，数据打到同一扇门口。

「授权 / 免授权」是这家开没开某个模块，不是「给这家单独做一个小程序」。

## 「数据接入助手」是什么（iSESOL 样例）

不是给工人点的报工页，是给「要用数据的人 / 对接别的软件」的付费能力。

```text
机床 → iSESOL BOX（现场采集盒子）
     → 数据接入助手（开通后给一个数据端口）
     → 设备云眼 / 第三方系统 / 开发者
```

截图原意：连上助手，用给定端口访问 BOX 的实时数据。年费约 3600，不是买盒子本身。

和另外两个应用的差别：

| 应用 | 干什么 |
|---|---|
| 数据接入助手 | 把盒子数据对外开放 |
| 设备云眼 | 给人看监控、时长、产量 |
| 应用管家 | 管盒子上要装哪些应用 |

对应你们清单里的 **设备联网数据采集** 的「出口」：没有接入，监控/能耗/安灯就没有活数据；有接入也不等于已经有看板。
