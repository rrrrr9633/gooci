## 已经拍板的总图

```text
你们公司
  1 个已备案域名
  1 扇门口（域名只解析到它）
  后面按需加：程序机 / 云数据库 / 对象存储
  全是普通规格，同一 VPC 内网互通

客户
  同一个网址登录
  同一个小程序打开
  账号决定是哪家工厂、开了哪些模块
  不买域名、不备案、不买服务器

模块
  模板复制 → 定制包 → 植入
  路径：/工作台/模块名
  不能停机就旁挂，能停机就并入主后端

本地不能联网
  EXE 启动同一控制台
```

## 三句口诀

1. **全中国客户共用你们一个已备案域名、一个小程序；靠登录分用户。**
2. **域名只指向门口；其它云服务器买在同一家云、同一地区、同一 VPC，走内网。**
3. **模块按需植入，不预装 20 个；50 台设备开张：16 核 32G + 系统盘 100G + 数据盘 200G 可以先上。**
