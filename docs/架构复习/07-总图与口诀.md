## 已经拍板的总图

```text
你们公司
  1 个已备案域名
  1 扇门口（域名只解析到它）
  后面按需加：程序机 / 模块公网下一跳 / 云数据库 / 对象存储
  客户共用这一套，靠登录和企业 ID 隔离，不按客户搭 VPC

客户
  同一个网址登录
  同一个小程序打开
  账号决定是哪家工厂、开了哪些模块
  不买域名、不备案、不买服务器

模块
  模板复制 → 定制包 → 植入
  路径：/工作台/模块名
  不能停机就旁挂，能停机就并入主后端
  旁挂下一跳：门口转发到允许名单里的公网 https；浏览器不直连；生产不走本机回环
  测试档只把 AI 中台转到本机 harness，其它模块仍拒绝回环

本地不能联网
  EXE 启动同一控制台
```

## 三句口诀

1. **全中国客户共用你们一个已备案域名、一个小程序；靠登录分用户。**
2. **域名只指向门口；模块由门口转到允许名单内的公网 https。AI 功能走同一条中台门口。生产不回环；测试档只转发 AI 中台到本机。库和文件不对公网开。**
3. **模块按需植入，不预装 20 个；50 台设备开张：16 核 32G + 系统盘 100G + 数据盘 200G 可以先上。**
