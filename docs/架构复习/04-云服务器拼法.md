# 04 云服务器怎么拼

[← 目录](README.md)

---

## 会不会要买一台巨大的云服务器

**不用。** 也不存在好买的「无限大一台」。

客户变多 = **多买几台普通云服务器拼在一起**，不是把一台越买越大。

```text
www.goci.com
    ↓
门口（入口，域名只指这里）
    ↓
房间1  8核32G
房间2  8核32G
房间3  16核64G
……以后再加房间
```

阿里云 / 腾讯云 / 华为云卖的就是 2 核、4 核、8 核、16 核。  
先买 1 台普通机就能开张。加机器时客户网址不变。

## 迷点：每台都有公网，怎么拼进一个域名

每台云服务器都可以有公网 IP，但 **不必都写进域名**。  
域名只认一个门牌号（门口那台的公网）。

请求怎么走：

```text
1. 电脑问：goci.com 是哪个 IP？  答案只有门口 1.1.1.1
2. 请求打到门口
3. 门口按路径内网转发：
     /工作台     → 程序机 192.168.0.20
     数据        → 程序机再问数据库机 192.168.0.30
4. 结果仍从门口回到浏览器
```

「拼」= **只有门口暴露公网；别的机器走内网，由门口转发。**

| 角色 | 要不要公网 | 写不写进域名 |
|---|---|---|
| 门口 | 要 | 只写它 |
| 程序 / 数据库 / 文件 | 最好不要公网，只要内网 | 不写 |

必须：**同一云账号、同一地域、同一个 VPC（专有网络）**。  
上海一台 + 北京一台，内网拼不上。

## 去哪买「程序机、数据库机、文件机」

还在你买第一台的那家云控制台买，不是另一种商品、也不是另一家公司。

| 角色 | 控制台里买什么 |
|---|---|
| 门口 / 程序 | 再买一台普通「云服务器」 |
| 数据库 | 优先买「云数据库」（比自己开一台装库省事） |
| 文件/图纸 | 买「对象存储」，这是网盘，不是又一台服务器 |

开张甚至 **先别买**：一台把程序、库、文件全装完。人多了再拆。

已开了好几台：

- 同一 VPC：指定一台当门口，其余当程序/库，暂时不用的可关机停费。
- 不同地域：只能留一个地区来拼。

合并就三步：同一 VPC → 记下内网 IP → 填进门口通讯录。域名一行都不用改。

## 按已有台数怎么分工

```text
1 台：全放一起，先开张

2 台：门口+程序 / 数据库

3 台：门口 / 程序 / 数据库+文件

4 台+：门口 / 两台程序互备 / 数据库 / 文件或采集
```
