# 04 云服务器怎么拼

[← 目录](README.md)

---

## 会不会要买一台巨大的云服务器

**不用。** 也不存在好买的「无限大一台」。

客户变多 = **多买几台普通云服务器拼在一起**，不是把一台越买越大。

```text
www.goci.com
    ↓
门口（入口，域名只指这里）
    ↓
房间1  8核32G
房间2  8核32G
房间3  16核64G
……以后再加房间
```

阿里云 / 腾讯云 / 华为云卖的就是 2 核、4 核、8 核、16 核。  
先买 1 台普通机就能开张。加机器时客户网址不变。

## 迷点：每台都有公网，怎么拼进一个域名

每台云服务器都可以有公网 IP，但 **不必都写进域名**。  
域名只认一个门牌号（门口那台的公网）。

请求怎么走：

```text
1. 电脑问：goci.com 是哪个 IP？  答案只有门口 1.1.1.1
2. 请求打到门口
3. 门口按路径转发（不写进域名）：
     /工作台     → 程序机
     /ext/模块   → 开通表里的公网 https 下一跳（须在允许名单）
     数据        → 程序机再问数据库（库不要对公网暴露）
4. 结果仍从门口回到浏览器
```

「拼」= **只有门口暴露给浏览器；模块可以在别的公网机器，由门口转发；库和文件不要对公网开。**

| 角色 | 要不要公网 | 写不写进域名 |
|---|---|---|
| 门口 | 要 | 只写它 |
| 模块下一跳 | 要（给门口访问，安全组只放行门口） | 不写 |
| 数据库 / 文件 | 不要 | 不写 |

门口和库尽量同一家云、同一地域，少走冤枉路。模块不必再塞进同一 VPC：填进门口通讯录（允许名单 + `TARGET_URL`）即可。域名一行都不用改。

已开了好几台：指定一台当门口，其余按上表分工，暂时不用的可关机停费。

合并就三步：记下模块公网主机 → 写入允许名单 → 填进开通表。域名一行都不用改。

## 去哪买「程序机、数据库机、文件机」

还在你买第一台的那家云控制台买，不是另一种商品、也不是另一家公司。

| 角色 | 控制台里买什么 |
|---|---|
| 门口 / 程序 | 再买一台普通「云服务器」 |
| 数据库 | 优先买「云数据库」（比自己开一台装库省事） |
| 文件/图纸 | 买「对象存储」，这是网盘，不是又一台服务器 |

开张甚至 **先别买**：一台把程序、库、文件全装完。人多了再拆。

## 按已有台数怎么分工

```text
1 台：全放一起，先开张

2 台：门口+程序 / 数据库

3 台：门口 / 程序 / 数据库+文件

4 台+：门口 / 两台程序互备 / 数据库 / 文件或采集
```
