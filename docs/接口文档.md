# GOOCI 控制台接口文档

版本与代码同步：`gooci-console 0.1.0`。当前后端只实现下列接口，本文按实现逐字段列出。未实现的能力在文末「明确没有」一节，避免误用。

机器可读副本：同目录 `openapi.yaml`。

## 1. 基址

| 场景 | 基址 |
| --- | --- |
| 生产网关 | `https://$GOOCI_PUBLIC_DOMAIN`（暂定 `https://goocidata.top`），路径以 `/api` 开头 |
| Content-Type | 请求体 JSON 用 `application/json;charset=UTF-8` |
| 字符集 | UTF-8 |
| 时区 | `Asia/Shanghai` |

前端 `axios`：`baseURL=/api`，超时 15000ms。下文路径一律写完整 `/api/...`。

## 2. 统一信封 `ApiResult`

所有业务接口（含失败）的 JSON 外壳：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | number | `0` 成功；`1` 失败 |
| `message` | string | 成功固定 `"ok"`；失败为原因文案 |
| `data` | object / null | 成功为业务体；失败为 `null` 或不出现 |

成功 HTTP 状态码为 `200`。业务失败（校验、账号密码错误等）也是 **HTTP 200 + `code=1`**，不要只看 HTTP 状态。

未登录访问受保护接口：HTTP **401**，body 仍是信封：

```json
{ "code": 1, "message": "未登录或登录已过期", "data": null }
```

## 3. 鉴权

| 项 | 约定 |
| --- | --- |
| 算法 | JWT，HMAC-SHA，密钥 `gooci.jwt-secret` |
| 有效期 | 12 小时（`gooci.jwt-expire-hours`） |
| 传递 | 请求头 `Authorization: Bearer <token>` |
| 无刷新令牌 | token 过期必须重新登录 |
| 无服务端登出 | 前端清 `localStorage.gooci-token` 即退出 |

匿名可访问：

- `OPTIONS /**`
- `POST /api/auth/login`
- `POST /api/auth/sms`
- `POST /api/auth/register`
- `GET /api/site/meta`
- `POST /api/ops/auth/login`

其余 `/api/**` 必须带有效 Bearer。非法/过期 token 视为未登录，返回 401。

企业 token（无 `scope` 或 `scope=enter`）不能调 `/api/ops/**`。厂商 token（`scope=ops`）不能调 `/api/console/**`。厂商退出清 `localStorage.gooci-ops-token`。

跨域允许来源由 `GOOCI_CORS_ORIGINS` 注入；方法 GET/POST/PUT/DELETE/OPTIONS；允许携带 Cookie 头。同域部署时不依赖 CORS。

## 5. GET `/api/site/meta`

官网公开信息。不登录可调。工作台也会调一次，用于顶栏电话。

**请求**：无 Query、无 Body。

**成功 `data`**

| 字段 | 类型 | 必有 | 说明 |
| --- | --- | --- | --- |
| `brandName` | string | 是 | 固定 `"GOOCI 谷器"` |
| `servicePhone` | string | 是 | 来自 `TS_SYS_PARAMETER.PARAM_CODE=SERVICE_PHONE` 的 `PARAM_VALUE`。库中无记录或值为 null 时返回 `""`。前端空串显示「预留」 |

**示例**

```http
GET /api/site/meta
```

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "brandName": "GOOCI 谷器",
    "servicePhone": ""
  }
}
```

## 6. POST `/api/auth/login`

**请求体 `LoginCommand`**

| 字段 | 类型 | 校验 | 说明 |
| --- | --- | --- | --- |
| `loginName` | string | 非空，否则 `"账号不能为空"` | 登录名 |
| `loginPassword` | string | 非空，否则 `"密码不能为空"` | 明文密码，服务端用 BCrypt 比对 |

**成功 `data`：`SessionView`**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | JWT，后续放 Header。仅登录接口返回 |
| `userId` | string | 用户 ID（UUID） |
| `displayName` | string | 显示名 |
| `mobile` | string | 脱敏：长度 ≥ 7 时 `前3 + **** + 后4`；否则原样；可为 null |
| `roleName` | string | 角色名，演示数据为 `"企业管理员"` |
| `enterId` | string | 企业 ID，对应用户 `TS_ENTER_ID` |
| `enterName` | string | 企业名；用户无企业时可能缺省 |
| `regionText` | string | 地区文案 |
| `certStatus` | string | `"1"` 已认证，其它视为未认证。无企业时可能缺省 |
| `servicePhone` | string | 同站点客服电话，可能 `""` |
| `menus` | `MenuView[]` | 菜单树，见第 8 节 |

`MenuView`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 菜单 ID |
| `menuCode` | string | 编码，前端根图标用 |
| `menuName` | string | 显示名 |
| `routePath` | string | 前端路由，如 `/workbench/home` |
| `iconCode` | string | 仅根节点有。取值：`monitor` / `office` / `collection` / `lock` / `grid`。子节点为 null |
| `children` | `MenuView[]` | 子菜单，缺省空数组 |

**失败（HTTP 200, `code=1`）**

| message | 条件 |
| --- | --- |
| `账号不能为空` | 缺字段或空串（校验） |
| `密码不能为空` | 缺字段或空串（校验） |
| `账号或密码错误` | 用户不存在或 BCrypt 不匹配 |

**示例**

```http
POST /api/auth/login
Content-Type: application/json

{"loginName":"admin","loginPassword":"GooCi@2026"}
```

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "token": "<jwt>",
    "userId": "<uuid>",
    "displayName": "管理员",
    "mobile": "138****0000",
    "roleName": "企业管理员",
    "enterId": "<uuid>",
    "enterName": "谷器演示工厂",
    "regionText": "待完善地区信息",
    "certStatus": "1",
    "servicePhone": "",
    "menus": []
  }
}
```

`menus` 完整结构见第 8 节，登录与 session 接口同一棵树。

## 6.1 POST `/api/auth/sms`

演示环境不接短信通道。成功时 `data.demoCode` 为 6 位数字，前端提示用。5 分钟有效，校验通过后在注册成功时作废。

**请求体 `SmsCodeCommand`**：`mobile` 非空，需匹配 `1` + 10 位数字，否则 `请填写正确的手机号`。

## 6.2 POST `/api/auth/register`

成功 `data` 同登录 `SessionView`（含 token）。`registerKind`：`ENTERPRISE` / `PERSON`。

**请求体 `RegisterCommand`**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `registerKind` | string | `ENTERPRISE` 或 `PERSON` |
| `mobile` | string | 登录名=手机号 |
| `smsCode` | string | 须匹配未过期验证码 |
| `displayName` | string | 姓名 |
| `loginPassword` | string | 至少 6 位 |
| `confirmPassword` | string | 须与密码一致 |
| `enterName` | string | 企业注册必填，公司名称 |
| `jobName` | string | 个人注册必填，职能 |
| `inviteCode` | string | 可空。个人填写时须等于某企业 `ENTER_CODE`（演示工厂为 `DEMO`） |
| `agreed` | boolean | 须为 true |

企业注册：新建企业（`certStatus=0`）+ 默认部门 + 企业管理员。个人带有效邀请码：加入该企业为员工。个人无邀请码：以姓名新建企业并成为管理员。

失败文案：`请阅读并同意平台协议`、`请填写正确的手机号`、`验证码错误或已过期`、`密码至少6位`、`两次输入的密码不一致`、`该手机号已注册`、`公司名称不能为空`、`请选择职能`、`邀请码无效`、`注册类型不正确`。

## 7. GET `/api/console/session`

取当前登录用户。Header 必须带 Bearer。

**与登录的差别**

- 不返回 `token`（JSON 里为 `null` 或不使用该值）
- 其余字段与登录成功体相同（含 `menus`、脱敏手机号、客服电话）

**失败**

| HTTP | code | message | 条件 |
| --- | --- | --- | --- |
| 401 | 1 | `未登录或登录已过期` | 无 Header、token 非法或过期（过滤器拦截，进不了 Controller） |
| 200 | 1 | `未登录` | 理论上 Holder 为空（正常会被 401 拦住） |
| 200 | 1 | `用户不存在` | token 里的 userId 在库中已删 |

## 8. GET `/api/console/overview`

工作台首页数字。未读条数、待办条数按当前登录人统计。设备数量仍为 `0`。**不做授权码。不做小程序自动传站内信。**

**成功 `data`：`ConsoleOverview`**

| 字段 | 类型 | 当前值 | 前端位置 |
| --- | --- | --- | --- |
| `unreadMessageCount` | number | 当前用户未读站内信条数 | 工作台右侧「未读信息」 |
| `pendingTaskCount` | number | 当前用户未处理待办条数 | 工作台右侧「待办任务」 |
| `linkedDeviceCount` | number | 0 | 右侧「已接入设备数量」 |
| `onlineDeviceCount` | number | 0 | 右侧「在线设备数量」 |
| `recentMessages` | array | 最多 8 条未读站内信 `{id, content}` | 右侧「消息动态」滚动 |

无 Query。鉴权失败同 session，HTTP 401。

## 9. 个人信息

工作台「个人信息」页。本页手机号返回库内明文，**不做脱敏**（与登录 / session 不同）。邮箱未填时 `mailAddr` 为空串，前端显示「请添加邮箱」。角色、部门、公司、已开通应用只读。角色后「管理」跳 `/workbench/org/structure`；部门后「管理」跳 `/workbench/org/dept`。

已开通应用不是控制台菜单模块，只是授权行。演示环境写 2 条，不预装产品目录里的 20 个模块。

## 16. 库表（接口读写到的）

`TM_ENTER` 企业（含简介、省市区、性质、规模、认证时间、工商/银行变更申请字段）；`TM_SYS_USER` 用户（含 `MAIL_ADDR`、`STAFF_CODE`、`REMARK_TEXT`、`WECHAT_NO`、`DING_NO`、`CARD_NO`）；`TM_SYS_MENU` 菜单；`TS_SYS_PARAMETER` 参数；`TM_DEPT` 部门；`TR_USER_DEPT` 用户部门；`TR_USER_APP_GRANT` 用户已开通应用（功能/数据角色名可顿号拼接）；`TM_APP_OPEN` 企业已开通（已植入）APP（含 `HIDE_FLAG`、`ENTRY_PATH`、`TARGET_URL`，有入口才进工业 APP 页；`TARGET_URL` 是内网模块机，空则网关出本地壳）；`TM_APP_ROLE` 功能/数据角色目录；`TM_DEVICE` 设备（含编号、类型、制造商、安装位置、购置日期、状态、等级、包机人、备注、联网标记）；`TM_DEVICE_CODE_RULE` 设备编号流水与列配置；`TM_DEVICE_FIELD` 设备自定义字段；`TM_DEVICE_FIELD_VAL` 设备字段取值；`TM_STAFF_CODE_RULE` 员工编号规则与列配置；`TM_STAFF_FIELD` 自定义字段；`TM_STAFF_FIELD_VAL` 字段取值；`TM_TODO` 待办（当前无写入）；`TM_INBOX` 站内信（当前用户收件，无自动推送）；`TM_OPS_USER` 厂商运营账号（不进企业用户表）。

逻辑删除字段 `IS_DELETE`：`0` 正常 / `1` 删除。接口只读未删除行。

建表脚本：`backend/src/main/resources/db/schema.sql`。已有库补列：`schema-patch.sql`。查询索引按「表名 + I + 序号」补齐，I01 留给 UNIQUE。
